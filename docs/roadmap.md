# Workstation Roadmap

This roadmap tracks the development of my Linux DevOps workstation and the
skills being practised through the project.

## Completed

- Install and configure Fedora
- Configure the i3 window manager
- Configure remote access using xRDP and Remmina
- Configure Git identity
- Create a Git repository
- Connect the repository to GitHub using SSH
- Learn the Git working directory, staging area, and repository model
- Create the initial repository structure

## Current Focus

- Document the workstation configuration
- Place configuration files under version control
- Improve the terminal environment
- Practise a professional Git workflow

## Planned Work

### Terminal Environment

- Install and configure Kitty
- Install and configure Zsh
- Configure the Starship prompt
- Add fzf, zoxide, eza, and bat
- Configure tmux

### Development Environment

- Install and configure Neovim
- Configure language servers
- Add formatting and linting tools
- Configure Git integrations

### DevOps Tooling

- Docker and Docker Compose
- Ansible
- Terraform or OpenTofu
- Kubernetes
- CI/CD with GitHub Actions
- Monitoring and observability tools

### Automation

- Package installation script
- Configuration deployment script
- Workstation update script
- Configuration backup and validation
